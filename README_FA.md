## نسخه 2.8 — شروع اتصال فروشگاه مشترک
- افزودن `StorePortal.kt` برای ورود به حساب فروشگاه، دریافت نقش از سرور، نمایش وظایف قابل مشاهده و ثبت انجام وظیفه.
- صفحه فروشگاه به API مشترک `https://iborn.pythonanywhere.com/api/v1` متصل می‌شود؛ اطلاعات شخصی همچنان محلی است.
- مجوز اینترنت برای اپ افزوده شد.
- این مرحله هنوز پنل کامل مدیریت شیفت/کارکنان و فرم‌های CRUD را تکمیل نکرده و Build اندروید در این محیط اجرا نشده است.

## نسخه 2.9 — پنل Store و مدیریت فروشگاه
- ورود پایدار به حساب Store و تشخیص نقش manager/staff از پاسخ سرور.
- پنل مدیر برای ساخت و غیرفعال‌کردن کارکنان، زمان‌بندی شیفت‌های تاریخ‌دار، ساخت/ویرایش/حذف وظایف عمومی و اختصاصی و ثبت محصول و سری‌های انقضا.
- پنل کارمند برای مشاهده برنامه شیفت و همکاران همان شیفت، وظایف عمومی مجاز و وظایف اختصاصی خودش.
- تکمیل وظیفه عمومی توسط کارکنان همان شیفت و نمایش آمار تکمیل برای مدیر.
- توکن ورود در SharedPreferences نگهداری می‌شود؛ خروج دستی یا لغو دسترسی باعث ورود مجدد می‌شود.
- داده‌های شخصی همچنان روی گوشی باقی می‌مانند و وارد API فروشگاه نمی‌شوند.
